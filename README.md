# AETHER AI — Final Website Package

This package is the clean website version for AETHER AI Weather.

## Included
- Live worldwide place search with exact-place selection
- Live weather and 7-day forecast using Open-Meteo
- Celsius / Fahrenheit
- World local time and timezone information
- Leaflet + OpenStreetMap map
- Driving directions using OSRM
- Browser voice input and spoken responses
- Multiple language/script support
- PWA manifest and service worker
- AETHER logo and app icons

## GitHub Pages
Upload the CONTENTS of this folder to the root of the `main` branch so that `index.html` is directly in the repository root.

Do not upload the outer ZIP file as a substitute for the website files.

## Important
The `/api/ai` endpoint is intended for a separate backend. GitHub Pages is static hosting, so a private AI API key must not be placed in `app.js` or any public GitHub file.
